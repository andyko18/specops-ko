# docs/audit — 자기 평가·제안 스냅샷

이 디렉토리는 specops-ko 가 **자기 자신을 측정한 결과**를 담는다.

## 왜 `.specops/` 가 아니라 여기 있는가

[CLAUDE.md](../../CLAUDE.md) 정책상 `.specops/` 는 **전량 로컬 전용**(`.gitignore`)이다 —
FID 아티팩트·리뷰 리포트·gbrain 기록이 커밋되지 않는다. `/doctor` 가 `memory: 문서 0건` 을
항상 경고하는 것도 같은 정책의 결과이고, 그건 고칠 결함이 아니라고 문서화돼 있다.

그런데 **평가서와 제안서는 성격이 다르다**:
- 델타 평가는 **후속 평가자가 이전 회차를 읽어야** 성립한다(루브릭·축·가중·사전 등록 트리거).
- 제안서는 **도입 검토자**가 "이 도구가 자기 결함을 어떻게 다루는가"를 판단하는 근거다.

로컬에만 두면 clone 한 사람은 둘 다 볼 수 없다. 그래서 **의도적 예외**로 여기에 둔다.

## 규약

- **날짜 고정 스냅샷이다.** 사본은 갱신하지 않는다 — 원본(`.specops/audit/`)과 드리프트하지 않는 이유.
  사실이 바뀌면 새 회차를 추가하지 기존 회차를 고치지 않는다.
- 파일명은 `YYYY-MM-DD-<slug>.md` (`docs/case-studies/` 와 동일 규약).
- 본문 수치는 그 시점 실측이다. 추정치는 그렇다고 표시한다.
